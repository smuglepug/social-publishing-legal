How it works

The tool runs on the creator’s own computer. It connects to each platform using that platform’s official authorisation flow, then sends video files on a schedule.

Connecting an account

No password is ever entered into this tool. Authorisation happens on the platform’s own website, and the platform returns a token that the tool stores locally.

Step 1

Start the connection

In the tool, choose the platform you want to publish to and click Connect.

Step 2

Authorise on the platform

The tool opens the platform’s official authorisation page in your browser. You sign in there, directly with the platform, and review the permissions being requested.

Step 3

Return to the tool

After you approve, the platform redirects back to a local address on your own computer. The tool exchanges that one-time code for an access token and stores it locally. You can revoke it at any time from your account settings on the platform.

Publishing a video

Step 1

Choose the file

Select a video file from your own computer, and write the title, caption and tags.

Step 2

Choose where it goes

Pick which connected accounts the video should be sent to, and when.

Step 3

Send it

The tool transmits the file to each platform’s API. Depending on the destination and how you have configured it, the video either appears on your profile, or lands in your drafts for you to review and publish yourself.

Permissions requested, and why

TikTok — user.info.basic

Reads the connected account’s display name and avatar. Used only to show you which account is connected, so you can confirm the tool will post to the right place.

TikTok — video.upload

Uploads a video to the connected account’s TikTok inbox as a draft. The video is not published; it waits for the creator to review and post it in the TikTok app.

TikTok — video.publish

Publishes the creator’s own video directly to the connected account. Used only for content the creator has chosen and scheduled, at the privacy setting they select.

Every upload is a file the operator created or holds the rights to. The tool does not accept content from third parties, does not post on behalf of anyone other than the account owner, and does not access other users’ data.

Where your data lives

Access tokens and video files are stored on the operator’s own computer. They are not sent to any server operated by this tool, because there is no such server — the tool talks directly to each platform’s official API over an encrypted connection.
