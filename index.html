Publish your own video content, on a schedule.

Social Publishing Automation is a desktop tool for creators who publish their own original video content. It connects to your own social accounts, queues your own video files, and publishes them to the platforms you choose — TikTok, Instagram, Facebook and YouTube.

See how it works

What it does

The tool exists to remove the repetitive part of publishing: choosing a file, writing a caption, opening each platform, and uploading the same video four times. You supply the content and the schedule; the tool handles the sending.

Your own accounts only

It publishes to accounts you own and explicitly connect. It never accesses anyone else’s account.

Your own content only

Every file is one you created or have the rights to. Nothing is generated from or uploaded on behalf of third parties.

You approve before it goes live

Uploads can be delivered as drafts so you review and publish them yourself in the app.

Runs on your own machine

Credentials and video files stay on your computer. Nothing is stored on a third-party server.

Supported platforms

  • TikTok — via the official Content Posting API and Login Kit
  • Instagram — via the Meta Graph API content publishing endpoints
  • Facebook — via the Meta Graph API video publishing endpoints
  • YouTube — via the YouTube Data API v3

Each integration uses that platform’s own official API and that platform’s own authorisation flow. You sign in directly with the platform; this tool never asks for your password.

Who it is for

It is a personal tool, operated by a single creator for their own channels. It is not offered as a hosted service to the public. If you are looking for a team publishing platform, this is not that product.
